Dissociation
Visual Pattern Break

A CSS-driven visual distortion effect that makes the current page feel suddenly unfamiliar — jolting you out of autopilot mode and forcing conscious re-engagement with the content.

Concept

Breaking the trance with visual disruption

When the extension activates, dissociationSwitch() toggles two CSS classes on the <html> element: .dissociation-prepare and .dissociated. These classes trigger SCSS-defined transformations that alter the entire page's visual properties — creating a jarring but harmless "dissociation" effect that interrupts mindless scrolling.

Mechanism

How the effect works

Class Toggle

The function dissociationSwitch() toggles .dissociation-prepare and .dissociated on the root <html> element.

CSS Cascade

The SCSS files (dissociate.scss, wyah.scss) define transforms, filters, and opacity changes that cascade to all child elements when these classes are active.

Transition Animation

A 0.5s transition duration creates a smooth, disorienting shift rather than an abrupt change — more effective at triggering conscious awareness.

Full Reversibility

Clicking again removes the classes, instantly restoring the page to its original state. No DOM modifications, no persistent changes.

Source Code

The toggle function

// wyah.js — dissociation toggle
function dissociationSwitch() {
  document.documentElement.classList.toggle('dissociation-prepare');
  document.documentElement.classList.toggle('dissociated');
  console.log('Class .dissociated toggled');
}

// Called immediately on script injection
dissociationSwitch();
Psychology

Why visual disruption works

The Orienting Response

When the brain detects an unexpected change in the visual environment, it triggers the orienting response — an involuntary shift of attention toward the novel stimulus. This is the same mechanism that makes you notice movement in your peripheral vision.

By subtly distorting a familiar page, the dissociation effect hijacks this response and redirects it toward conscious self-awareness. The user suddenly notices they are looking at a screen, rather than being absorbed by the content. This momentary "snap back" is the window in which the WYAH module's question becomes most effective.

The effect is designed to be uncomfortable but not aversive — enough to break flow state, not enough to cause annoyance or eye strain. The 0.5-second transition ensures gradual onset, avoiding a startling experience.
