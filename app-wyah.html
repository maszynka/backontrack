"Why Am I Here?"
The WYAH Module

The intent-capture engine of BackOnTrack. WYAH injects a minimal form into any webpage, asking you to declare your purpose before you get swept into the content stream.

Purpose

Capturing intent at the point of entry

When you click the BackOnTrack toolbar button, content_script.js fires and injects wyah.js into the active tab. This script creates a small, unobtrusive form at the top of the page with two fields: a text input asking "Why are you here?" and a number input for setting a reminder timer in minutes (default: 5).

The form is injected via Shadow DOM to prevent CSS conflicts with the host page. A fallback is provided for browsers that don't support Shadow DOM, with a notification linking to compatibility information.

Features

What WYAH delivers

  • 1

    DOM Injection via Shadow DOM

    The WYAH form is encapsulated in a Shadow DOM root, preventing any CSS leakage from the host page. This ensures the extension looks consistent everywhere.

  • 2

    Duplicate Prevention

    Before injecting, wyah.js checks if the element #wyah already exists. If it does, the script exits gracefully — no duplicate forms, no errors.

  • 3

    Integrated Dissociation Trigger

    On activation, WYAH immediately calls dissociationSwitch(), toggling the visual distortion effect on the host page to create an immediate "pause" moment.

  • 4

    CSS Reset Isolation

    A comprehensive CSS reset (reset.css) ensures the WYAH form elements render identically across all websites, regardless of the host page's stylesheet.

  • 5

    Auto-growing Textarea

    The input area uses a mirrored hidden element to dynamically grow as you type, accommodating longer explanations of intent without scrolling.

Source Code

Core injection logic

// content_script.js — entry point
chrome.browserAction.onClicked.addListener(function(tab) {
  chrome.tabs.executeScript(null, {file: "js/wyah.js"});
  chrome.tabs.insertCSS(null, {file: "css/wyah.css"});
});

// wyah.js — DOM injection
function wyahInit() {
  var htmlString = '<form id="wyah-form">'
    + ' <input type="text" placeholder="Why are you here?"/>'
    + ' <label><input id="wyah-f-minutes" type="number"'
    + '  placeholder="5"/>minutes</label>'
    + '</form>';

  var div = document.createElement('div');
  div.id = "wyah";
  var root = div.createShadowRoot();
  root.innerHTML = htmlString;
  document.documentElement.appendChild(div);
}
